\# SQL Practice



This directory contains my structured SQL practice across 10 progressive phases.



\## Learning Path



1\. SQL Foundations

2\. Aggregations

3\. JOINs

4\. Subqueries

5\. Window Functions

6\. Common Table Expressions (CTEs)

7\. CASE WHEN \& Business Logic

8\. Date \& Time Functions

9\. String Functions

10\. Advanced SQL Analytics



Each phase contains topic-based practice queries, interview-oriented questions, scenario-based problems, and advanced analytical patterns.



The queries are written for MySQL and use the `CO` database included in the `database/` directory.
